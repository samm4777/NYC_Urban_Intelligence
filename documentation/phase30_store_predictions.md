# Prediction Error

The warehouse stores signed prediction error:

    prediction_error
        =
    predicted_taxi_demand - actual_taxi_trips

Interpretation:

    positive error
        = model overprediction

    negative error
        = model underprediction

Keeping the signed value preserves more analytical information than storing
only an absolute error.

## Percentage Error

Percentage error is calculated only where:

    actual_taxi_trips > 0

When actual taxi demand equals zero:

    percentage_error = NULL

This avoids division-by-zero and unstable normal MAPE calculations.
